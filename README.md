# MetaTrader5 Connector
If free data is desired, MT5 is likely the best choice

This script fetches all Market Watch Symbols data to a folder/sub-folders for use by other scripts, e.g., Machine Learning training or synthetic data ingredients.

# Use
This script can be run in a Python venv with required dependencies

Do "python mt5_connector.py will show required wheels in terminal

For instalnce, just do "pip install setproctitle" if crashes on "no module named setproctitle"

Each venv of python verions may have different requirements.

So just install the misisng wheels one-by-one

# Compiling
If you must run as binary:

Ask any free LLM to help compile (very easily) into binary in your OS setup.

Everyone has different configurations.

Providing binaries for Windows alone can be tedious.

For Wine compiling, it is straightforward.
